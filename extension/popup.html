职位采集

刷到职位列表页（牛客 / 官网招聘列表）点一下，把这一页的岗位收进求职app的匹配池。翻一页采一次。
在职位列表页点「采集本页职位」。

投递回执

停在「提交成功页」或某条投递的详情页，生成一张提交凭证（投了没 / 什么时候投 / 申请号）。
点下面的按钮，从当前页面生成回执。

辅助填写

在公司官网的申请表页：粘贴求职app「准备投递」弹窗里「复制填表数据」导出的 JSON，代填输入框。只填不提交——最后那一下由你亲手点。
你只需要粘贴一次。扩展会自动分三步填：① 姓名 / 邮箱这类普通输入框；② 页面上经历段块不够时，自动点「添加工作 / 项目经历」按钮补出表单；③ 公司名称、起止时间这类要点开检索列表或日历面板的栏（中间停几秒是在模拟真实点击，属正常）。各段经历按名称和时间对应：项目时间跟着项目名走，不会串到别的经历上；全新的空白表单则按页面上的段块顺序对应。只有某几段的名称栏里已经有内容、却和资料对不上时，那几段的时间才会先不填并提示你——核对后再点一次即可。
把填表 JSON 粘到下面，点「填充当前页」。

探测表单结构（填不上时用这个）

有些栏填不动，是因为每家官网的组件都不一样。这个按钮不改页面、不填值，只把当前页每个可填控件的「标签写在哪儿、用的是什么组件、是不是只读、是不是下拉」导成一份清单。复制后发给开发者，就能针对这一页写适配，不用继续猜。
日期 / 下拉栏填不动时多一步：先把它点开（让面板弹出来），再点这个按钮 —— 面板的结构会一起导出，那才是真正缺的那块。
停在填不动的那个表单页，点「探测本页表单」。

院校项目采集

停在某个学校 PhD/MPhil 项目的详情页，点一下，抓出 program/deadline/fund/语言要求/项目介绍。复制 JSON 后回求职app「申学规划 → 导入院校项目」粘贴入库。
在项目详情页点「采集本页项目」。
