# 职引 · 浏览器采集扩展

一个零依赖的 Chrome / Edge 扩展（Manifest V3，原生 JS），用于把已保存的材料**填进真实的招聘官网表单**。

## 它做什么

在招聘网站的申请页面上，扩展会：

1. **识别页面**：判断这是哪家招聘系统（内置常见 ATS 的域名与结构规则）
2. **扫描表单**：找出页面上所有可填字段，并推断每个字段要什么
3. **逐字段填充**：从你保存的经历、教育、技能里取对应内容填进去
4. **如实汇报**：告诉你填上了什么、跳过了什么、哪些没填上

## 两条刻意的设计

**① 跳过的东西会明说。**
证件号码、密码、`type=file` 的上传框 —— **一律不填**，并在汇报里写明原因。
假象比漏填更糟：用户以为填上了、结果没填，比明确知道"这一栏要我自己来"危险得多。

**② 填不上绝不硬填。**
遇到不认识的下拉框、自研组件库，宁可留空并记一条 `missed`，
也不猜一个看起来像的值填进去。

## 安装

1. 打开 `chrome://extensions`（Edge 是 `edge://extensions`）
2. 右上角打开**开发者模式**
3. 点**加载已解压的扩展程序**，选择本目录

因为扩展需要读取当前页面才能填表，浏览器会要求你确认相应权限。
**扩展不上传任何数据** —— 它没有后端，所有处理都在你的浏览器里完成。

## 文件

| 文件 | 作用 |
|---|---|
| `manifest.json` | 扩展声明（权限、注入范围） |
| `popup.html` / `popup.js` | 点击图标后的面板：扫描、填充、汇报 |
| `extractor.js` | 注入到页面里的提取器：表单识别、标签匹配、日期面板操作 |
| `rules.json` | 各招聘系统的域名与结构规则 |
